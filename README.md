# 🔐 Wireshark SOC Labs

## 📌 About

This repository contains my work for the NetworkWalks Cybersecurity Internship. I completed six Wireshark labs focused on network traffic analysis and investigating different types of network activity.

The labs gave me practical experience with TCP streams, HTTP traffic, brute-force activity, and VoIP communication. I have included screenshots of my results for reference.
