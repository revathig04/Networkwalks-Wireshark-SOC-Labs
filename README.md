# 🔐 NetworkWalks Wireshark SOC Labs

## 📌 About This Project

This repository contains my practical work completed as part of the **NetworkWalks Cybersecurity Internship**.

Through these Wireshark SOC labs, I practiced analyzing network traffic, investigating suspicious activities, and understanding how packet analysis supports security monitoring and investigation.

I completed six labs covering TCP communication, attacker identification, HTTP credentials, brute-force activity, and VoIP traffic. Screenshots of my lab results are included in this repository.

## 🛠️ Tools Used

- 🦈 **Wireshark** — Network packet capture and analysis
- 🌐 **TCP/IP** — Understanding network communication
- 🔎 **HTTP and FTP** — Application traffic analysis
- 📡 **Network Protocols** — Investigating communication patterns

## 🧪 Labs Completed

| Lab | Lab Name | Key Learning |
|---|---|---|
| Lab 3 | Identify the Attacker's IP | Examining TCP SYN packets and identifying the suspected attacker |
| Lab 4 | Follow TCP Stream I | Following TCP conversations and examining transmitted data |
| Lab 5 | Follow TCP Stream II | Investigating TCP stream contents |
| Lab 6 | HTTP Plain Text Credentials | Understanding how unencrypted HTTP traffic can expose credentials |
| Lab 7 | Brute Force Catch | Recognizing patterns associated with repeated login attempts |
| Lab 8 | VoIP Call Replay | Examining VoIP traffic and understanding voice communication analysis |

## 🎯 Skills Practiced

- 🔍 Network traffic and packet analysis using Wireshark
- 📦 TCP packet inspection and stream analysis
- 🚨 Investigation of suspicious network activity
- 🖥️ Identification of suspected attacker IP addresses
- 🔑 Understanding plaintext credential exposure
- 🛡️ Recognition of possible brute-force attempts
- 📞 VoIP traffic analysis
- 📊 Interpretation of packet details and communication patterns
- 📝 Documentation of lab findings
